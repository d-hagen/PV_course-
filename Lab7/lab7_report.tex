\section{Packet Formal Statements}

Planned \texttt{assume}/\texttt{assert} statements to be added in the
\texttt{`ifdef FORMAL} block of \texttt{packet.sv}.

\subsection*{Assumptions}
\begin{itemize}[leftmargin=*]
    \item Start in reset.
    \item \texttt{chk\_ok} and \texttt{chk\_fail} are mutually exclusive.
\end{itemize}

\subsection*{Assertions}
\begin{itemize}[leftmargin=*]
    \item \textbf{State transitions} -- one per FSM edge.\\
        \textit{e.g.} \texttt{HEADER $\rightarrow$ PAYLOAD} when \texttt{hdr\_done}.
    \item \textbf{State holding} -- stay in the same state when the trigger is low.\\
        \textit{e.g.} \texttt{HEADER $\rightarrow$ HEADER} when \texttt{hdr\_done} is low.
    \item \textbf{Abort and reset} force the FSM to \texttt{IDLE}.
    \item \textbf{Reset clears} the output signals.
    \item \textbf{Output signals are single-cycle pulses.}
    \item \textbf{Output signals are mutually exclusive} and only asserted on the correct state transition.
\end{itemize}
